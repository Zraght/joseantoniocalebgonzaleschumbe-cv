⭐ Projects

💻 Technical Projects

  • 2026 – Completed

    Personal Expense Analysis System (CLI data pipeline)
    Python 3.10+ • pandas • NumPy • Matplotlib / Seaborn • openpyxl • pytest • Git

    Installable command-line tool that turns raw bank-export files into a statistical analysis and a shareable report. It runs a full ETL flow (ingestion → cleaning → analysis → visualization → reporting) and flags unusual transactions using a per-category z-score. Built as a practical project applying concepts from the Python for Everybody Specialization (University of Michigan) and Google IT Automation with Python coursework.

    • Ingestion & validation: reads .csv, .xlsx and .xls; checks 4 required columns, coerces types, removes duplicates and warns about skipped rows (invalid dates or amounts).
    • Anomaly detection: per-category z-score (default threshold 2.0, configurable); categories with fewer than 3 transactions are skipped. On the included 21-transaction sample it flags a $2,400 Food charge against a $579.83 category mean.
    • Outputs: 3 charts (bar, pie, monthly trend; 300 DPI by default) and a self-contained HTML report with base64-embedded images that opens offline.
    • Engineering practices: ~1,350 lines of Python across 4 processing modules and 3 utility modules; argparse CLI with exit codes; pyproject.toml packaging; rotating logs (10 MB × 5 backups); deep-merge JSON configuration.
    • Testing: 73 unit tests with pytest, covering reading, analysis, validation and configuration.

💻 Proyectos Técnicos

  • 2026 – Completado

    Sistema de Análisis de Gastos Personales (pipeline de datos por CLI)
    Python 3.10+ • pandas • NumPy • Matplotlib / Seaborn • openpyxl • pytest • Git

    Herramienta de línea de comandos instalable que convierte archivos exportados del banco en un análisis estadístico y un reporte compartible. Ejecuta un flujo ETL completo (ingesta → limpieza → análisis → visualización → reporte) y detecta transacciones inusuales mediante z-score por categoría. Desarrollada como proyecto práctico aplicando conceptos de la Especialización Python for Everybody (Universidad de Michigan) y del curso Google IT Automation with Python.

    • Ingesta y validación: lee .csv, .xlsx y .xls; verifica 4 columnas obligatorias, convierte tipos, elimina duplicados y advierte sobre filas omitidas (fechas o montos inválidos).
    • Detección de anomalías: z-score por categoría (umbral por defecto 2.0, configurable); se omiten categorías con menos de 3 transacciones. En el ejemplo incluido de 21 transacciones marca un gasto de $2,400 en Food frente a una media de categoría de $579.83.
    • Salidas: 3 gráficos (barras, pastel y tendencia mensual; 300 DPI por defecto) y un reporte HTML autocontenido con imágenes embebidas en base64 que abre sin conexión.
    • Prácticas de ingeniería: ~1,350 líneas de Python en 4 módulos de procesamiento y 3 de utilidades; CLI con argparse y códigos de salida; empaquetado con pyproject.toml; logs rotativos (10 MB × 5 respaldos); configuración JSON con deep-merge.
    • Pruebas: 73 pruebas unitarias con pytest que cubren lectura, análisis, validación y configuración.
